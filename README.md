Turnos Médicos

Sistema de gestión de turnos médicos-

Proyecto desarrollado con TypeScript, Node.js  y Express para la gestión de turnos médicos.

🚀 Tecnologías Utilizadas
Lenguaje: TypeScript

Entorno de Ejecución: Node.js (ES Modules)

Framework: Express.js

Validación: Zod

Ejecución en Desarrollo: tsx

Persistencia: Archivos JSON localizados en src/data/ (profesionales.json y turnos.json)
